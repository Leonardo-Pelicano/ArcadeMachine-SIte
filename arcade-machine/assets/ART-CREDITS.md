# Arte do Projeto Selene

Os desenhos vetoriais de foguetes, peças, objetos e cenários foram criados para este projeto. A ilustração transparente de Pelicano (pelicano-illustrated.png) foi produzida com geração de imagem assistida por IA a partir de uma descrição original do personagem, sem extrair arte do jogo homenageado.

Into Space!, de BarbarianGames, foi usado como referência de mecânica e organização da oficina. Código, diálogos, nomes de modelos e arte desta versão são próprios. Referência: https://www.kongregate.com/en/games/barbariangames/intospace

O áudio mantém seus créditos em audio/CREDITS.md.
